# Документация Form Service

Документация разделена по назначению:

- [Разработка](development.md) — запуск проекта, команды проверки и правила
  локальной разработки.
- [Архитектура](architecture.md) — устройство клиентской и серверной частей,
  границы модулей и основные потоки данных.
- [HTTP API](api.md) — актуальный контракт административных и публичных
  endpoint'ов.
- [Архитектурные решения](decisions/) — отдельные решения, которые важно
  сохранять при дальнейшем развитии проекта.
- [AI_LOG](../AI_LOG.md) — журнал существенных изменений, выполненных с
  помощью ИИ.

Для общего обзора проекта и быстрого запуска см. [главный README](../README.md).
