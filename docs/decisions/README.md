# Архитектурные решения

Здесь фиксируются решения, которые влияют на структуру проекта или публичный
контракт. Новую запись стоит добавлять, если решение сложно восстановить по
коду и оно важно для следующих изменений.

Формат записи:

1. Контекст и проблема.
2. Принятое решение.
3. Рассмотренные альтернативы.
4. Последствия для клиента, сервера и тестов.
